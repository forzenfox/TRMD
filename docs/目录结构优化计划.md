# TRMD 目录结构优化计划

> 创建时间：2026-07-20
> 状态：待执行

## 目标

消除冗余垫片文件、理清模块归属、将 `module/core/` 按子领域组织为子包、整理测试目录，提升项目可维护性和可读性。

## 阶段依赖关系

```
阶段一（垫片清理）──→ 阶段二（根级归类）──→ 阶段三（core子包化）──→ 阶段四（测试整理）
    可独立执行          依赖阶段一完成         依赖阶段二完成          依赖阶段三完成
```

每个阶段完成后必须：全部单元测试通过 → ruff 检查通过 → 单独 git commit

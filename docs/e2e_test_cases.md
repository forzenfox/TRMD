## 1. 测试范围与架构

### 1.1 测试框架

- **测试框架**: Playwright + Pytest
- **Page Object 模式**: `tests/e2e/pages/` 目录下封装页面对象
- **测试数据**: `tests/e2e/fixtures/` 目录下管理测试数据与配置
- **测试配置**: `tests/e2e/fixtures/e2e_test_config.yaml`

### 1.2 现有测试文件结构

```
tests/e2e/
├── conftest.py                    # 全局Fixture（服务连接、认证、浏览器）
├── debug_download_task.py         # 调试用下载任务脚本
├── fixtures/
│   ├── e2e_test_config.yaml       # E2E测试配置
│   ├── test_config.py             # 测试配置读取工具
│   ├── test_data_setup.py         # 测试数据准备fixture
│   └── task_helpers.py            # 任务操作辅助工具
├── pages/
│   ├── base_page.py               # Page Object基类
│   ├── login_page.py              # 登录页Page Object
│   ├── dashboard_page.py          # Dashboard页Page Object
│   ├── tasks_page.py              # 任务页Page Object
│   ├── files_page.py              # 文件页Page Object
│   └── config_page.py             # 配置页Page Object
└── web/
    ├── test_login.py              # 登录测试 (5类 7用例)
    ├── test_dashboard.py          # Dashboard测试 (9类 22用例)
    ├── test_tasks.py              # 任务管理测试 (25类 52用例)
    ├── test_files.py              # 文件管理测试 (17类 34用例)
    ├── test_config.py             # 配置管理测试 (18类 31用例)
    └── test_global.py             # 全局组件测试 (4类 6用例)
```

### 1.3 测试优先级定义

| 优先级 | 说明 | 示例 |
|--------|------|------|
| **P0** | 核心功能，阻断性 | 登录认证、任务创建、文件下载 |
| **P1** | 重要功能，影响主流程 | 分页、筛选、配置保存 |
| **P2** | 辅助功能，体验优化 | 通知样式、加载状态、文本格式化 |

## 2. 测试配置参数

### 2.1 现有配置参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `test_token` | string | "" | WebUI认证Token |
| `expired_token` | string | "" | 过期Token（测试过期跳转） |
| `api_id` | string | "" | Telegram API ID |
| `api_hash` | string | "" | Telegram API Hash |
| `test_source_channel` | string | "" | 下载测试源频道 |
| `test_target_channel` | string | "" | 转发/上传目标频道 |
| `auto_start_server` | bool | true | 是否自动启动服务 |
| `server_port` | int | 8080 | E2E测试服务端口 |
| `server_start_timeout` | int | 60 | 服务启动超时(秒) |
| `session_directory` | string | "sessions" | Session文件目录 |
| `run_real_tg_tests` | bool | true | 是否运行真实TG任务测试 |
| `prepare_test_data` | bool | true | 是否自动准备下载数据 |
| `test_download_count` | int | 5 | 下载测试数据条数 |
| `test_message_id_range` | dict | {min_id: 96396, max_id: 96404} | 消息ID范围 |
| `test_media_types` | list | ["photo"] | 下载媒体类型过滤 |
| `cleanup_test_data` | bool | false | 是否清理测试数据 |
| `test_single_file_timeout` | int | 60 | 单文件下载超时(秒) |
| `test_base_timeout` | int | 30 | 基础超时(秒) |
| `pagination_task_count` | int | 25 | 分页测试任务数量 |

### 2.2 建议新增配置参数

| 参数 | 类型 | 默认值 | 说明 | 用途 |
|------|------|--------|------|------|
| `test_repository_channel` | string | "" | 仓库频道标识符 | 测试仓库模式相关功能 |
| `test_invalid_channel` | string | "@nonexistent_channel_12345" | 无效频道标识符 | 测试频道解析失败场景 |
| `test_private_channel` | string | "" | 无权限私有频道 | 测试权限拒绝场景 |
| `test_upload_file_path` | string | "" | 上传测试文件路径 | 测试文件上传功能 |
| `test_forward_source_channel` | string | "" | 转发源频道（与下载源不同时使用） | 测试转发任务的源频道 |
| `api_response_timeout` | int | 15000 | API响应等待超时(ms) | 统一API超时配置 |
| `download_task_wait_timeout` | int | 120 | 下载任务等待超时(秒) | 动态计算下载超时 |
| `notification_wait_timeout` | int | 10000 | 通知等待超时(ms) | 等待通知出现/消失 |

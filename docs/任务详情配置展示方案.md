## 1. 背景与目标

### 1.1 背景

当前任务详情抽屉仅展示任务 ID、任务类型、状态、范围模式、类型过滤、子任务统计、进度、时间线和错误信息。用户在创建任务后无法直观查看任务的完整配置（如源频道、目标频道、具体范围参数、文件大小过滤等），不利于任务复核、问题排查和重复创建。

### 1.2 目标

在任务详情抽屉中**直接平铺展示**任务的完整配置信息，使用户无需跳转或重新打开创建表单即可查看任务参数。

---

## 2. 需求范围

### 2.1 纳入展示的配置

- 源频道/目标频道标识
- 消息范围的具体参数（按 `range_mode` 展示）
- 媒体类型过滤
- 文件大小过滤
- 上传任务的删除选项
- 资源预估信息（如有）

### 2.2 不纳入展示的配置

| 字段 | 不展示原因 |
|------|-----------|
| `file_paths`（上传文件路径列表） | 路径信息对用户无意义，且可能极长 |
| `enable_repository_backup`（仓库备份开关） | 创建表单暂无此选项，且属于内部策略配置 |
| 原始未解析的 Telegram chat_id（在已展示 `source_identifier` 或 `target_identifier` 时） | 避免冗余，优先展示用户可读的标识 |

### 2.3 截断规则

- 消息 ID 列表（`message_list`）过长时截断显示：最多展示 **5 条**，超出部分显示为"... 等 N 条"。
- 其他字符串类配置（如频道链接）按 CSS 自动换行或截断处理。

## 3. 总体设计

### 3.1 展示位置

在任务详情抽屉的现有信息区域中新增一个独立的"任务配置"区块，采用与"子任务统计"、"时间线"一致的卡片式样式（`bg-slate-900/50 rounded-lg p-4`）。

建议放置于"类型过滤"之后、"子任务统计"之前，使配置信息紧邻用户已熟悉的任务概览。

### 3.2 展示形式

- **平铺键值对**：每个配置项占一行，左侧为灰色标签，右侧为白色值。
- **条件渲染**：根据 `task_type` 和 `range_mode` 仅展示相关字段，避免无关空项。
- **空值处理**：未设置或不适用的字段不展示，或显示为"-"（统一约定）。

### 3.3 数据流

后端 `TaskOut` 已经返回完整 `params` 字段，前端无需新增 API 请求。详情抽屉通过 `selectedTask.params` 直接读取配置。

## 4. 字段展示规则（按任务类型）

### 4.1 通用展示字段

以下字段在所有非上传任务中根据是否存在展示：

| 字段 | 标签 | 格式化方式 |
|------|------|-----------|
| `source_identifier` / `chat_id` | 源频道 | 优先展示 `source_identifier`，否则展示 `chat_id` |
| `target_identifier` / `forward_target` / `chat_id` | 目标频道 | 转发/上传/监听转发任务展示 |
| `range_mode` | 范围模式 | 复用现有 `getRangeModeText()` |
| `filter_types` / `media_types` | 类型过滤 | 复用现有 `formatFilterTypes()` |
| `min_size` / `max_size` | 文件大小过滤 | 格式化为可读大小（MB/GB） |
| `estimated_size` / `size_human` | 预估大小 | 显示字节数和可读大小 |

### 4.2 按 `range_mode` 展示的范围详情

| range_mode | 展示字段 | 标签 | 说明 |
|-----------|---------|------|------|
| `id_range` | `min_id` | 最小消息 ID | 仅当存在时展示 |
| `id_range` | `max_id` | 最大消息 ID | 仅当存在时展示 |
| `date_range` | `start_date` | 开始日期 | 仅当存在时展示 |
| `date_range` | `end_date` | 结束日期 | 仅当存在时展示 |
| `multiple_ids` | `message_list` | 消息 ID 列表 | 最多展示 5 条，超出截断 |
| `recent` | `recent_count` | 最近消息数 | 显示为"最近 N 条消息" |
| `all` | - | 全部消息 | 显示提示文本 |

### 4.3 下载任务（download）

展示字段：

- 源频道
- 范围模式 + 范围详情
- 类型过滤
- 文件大小过滤（可选）
- 预估大小（可选）

### 4.4 转发任务（forward）

展示字段：

- 源频道
- 目标频道
- 范围模式 + 范围详情
- 类型过滤
- 文件大小过滤（可选）
- 预估大小（可选）

### 4.5 上传任务（upload）

展示字段：

- 目标频道
- 已选文件数量（由 `file_paths.length` 计算，不展示具体路径）
- 上传后删除本地文件（`delete_after_upload`）

### 4.6 监听下载任务（listen_download）

展示字段：

- 源频道
- 监听媒体类型（`media_types`）

### 4.7 监听转发任务（listen_forward）

展示字段：

- 源频道
- 目标频道
- 监听媒体类型（`media_types`）

## 5. 前端实现方案

### 5.1 HTML 模板层

在 [module/web/tasks.html](file:///d:/workspace/TRMD/module/web/tasks.html) 的任务详情抽屉中新增"任务配置"区块：

- 使用 `x-show` 根据 `selectedTask.params` 和 `selectedTask.task_type` 条件渲染。
- 范围详情部分使用嵌套 `template x-if` 按 `range_mode` 分支展示。
- 消息 ID 列表使用循环渲染，结合索引判断实现"最多 5 条 + 截断提示"。

### 5.2 JavaScript 逻辑层

在 [module/web/js/tasks.js](file:///d:/workspace/TRMD/module/web/js/tasks.js) 中新增或复用以下工具方法：

| 方法 | 用途 |
|------|------|
| `formatFileSize(bytes)` | 已存在，复用 |
| `formatIdList(ids, maxCount)` | 格式化 ID 列表，支持截断 |
| `formatSizeFilter(minSize, maxSize)` | 将字节大小格式化为"最小 X MB — 最大 Y GB" |
| `getTaskConfigFields(task)` | 返回当前任务应展示的配置字段数组（可选，用于测试） |

所有新增方法均为纯函数，便于单元测试。

### 5.3 样式

复用现有 Tailwind 工具类，不引入新 CSS：

- 标签：`text-sm text-slate-400`
- 值：`text-white mt-1`
- 卡片容器：`bg-slate-900/50 rounded-lg p-4 space-y-2`
- 分隔：`grid grid-cols-2 gap-4` 或 `space-y-3`

## 9. 风险与注意事项

1. **字段名不一致风险**：后端 `params` 中实际存储的转发目标字段需确认是 `forward_target` 还是 `target_identifier`，实现前需核对 task_executor 落库逻辑。
2. **Alpine.js 响应式**：详情抽屉使用 `selectedTask.params` 读取数据，新增字段需确保 `params` 已在后端 `TaskOut` 中完整返回（当前已满足）。
3. **长文本溢出**：源频道链接可能较长，需使用 `break-all` 或滚动处理。
4. **向后兼容**：`params` 中可能包含旧任务缺少的字段，展示逻辑需做空值判断。

# TRMD 人工测试指导文档

## 一、文档说明

本文档指导人工测试人员在自动化测试覆盖之外的场景下进行手动验证。当前项目已有 **674 个自动化测试用例全部通过**（覆盖率 95.2%），人工测试主要聚焦于：
- 需要真实 Telegram 连接的端到端集成测试
- 性能与压力测试
- 实际用户体验验证

## 二、测试环境准备

### 2.1 前置条件

| 配置项 | 说明 | 获取方式 |
|--------|------|---------|
| Python | 3.12+ | python.org |
| Telegram 账号 | 用于登录 Client | 手机号注册 |
| Bot Token | 测试用 Bot | @BotFather 创建 |
| api_id | Telegram API ID | my.telegram.org |
| api_hash | Telegram API Hash | my.telegram.org |
| 测试频道 | 源频道 + 目标频道 | Telegram 创建 |

### 2.2 环境配置

```yaml
# config.yaml 配置示例
bot:
  token: "YOUR_BOT_TOKEN"
  admins: [YOUR_USER_ID]

tg:
  api_id: 12345678
  api_hash: "your_api_hash"
  session_name: "trmd_session"

web:
  host: "127.0.0.1"
  port: 8000
  secret_key: "your_secret_key"
```

### 2.3 启动服务

```bash
# 启动 Web API + Bot
python main.py --web

# 验证服务状态
# Web API: http://127.0.0.1:8000/docs
# Bot: 在 Telegram 中搜索你的 Bot 并发送 /start
```

curl -H "X-API-Token: YOUR_TOKEN" http://127.0.0.1:8000/api/tasks
